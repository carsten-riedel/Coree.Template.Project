0.9.0 (2026-09-20)

 - Added the optional `WixUserInstaller` choice to the multi-console, multi-WinForms, and multi-WPF repository templates. `dotnet publish` feeds the normal app publish output to a separate per-user WiX project and writes `<app>.msi` under `bin/Setup/`; the technical project is `<app>.WixSetup`.
 - Documented the Visual Studio HeatWave requirement, WiX SDK CLI flow, and generated installer output in the root, NuGet, template, and solution README files.
 - Kept the default `None` installer choice and all existing `ProgramSample` defaults unchanged.

0.7.0 (2026-09-16)

 - Completed the classic multi-project repository template family: multi-library, multi-analyzer, multi-source-generator, multi-console, multi-msbuild, multi-PowerShell, multi-winforms, multi-wpf, and multi-project-template repositories with consistent repository, solution-placement, packaging, and Visual Studio/CLI conventions.
 - Multi-source-generator repository template (`multisourcegeneratorrepo-coree`): incremental C#-model-to-JSON-support sample, GeneratorDriver tests, Console DebugHost, and analyzer-path NuGet packaging.
 - Multi-WPF repository template (`multiwpfrepo-coree`): optional `MahAppsMvvm` program sample with Hosting/DI, CommunityToolkit.Mvvm, MahApps/Material Design, localization, configuration reload, and SQLite.
 - Multi-WinForms repository template (`multiwinformsrepo-coree`): optional `GenericHost` program sample with Generic Host, DI, logging, reloadable configuration, English/German/Spanish/French/Italian/Portuguese/Simplified-Chinese localization, profile optimization, and single-instance protection.

0.4.4 (2026-09-15)

 - Multi-winforms repository template (`multiwinformsrepo-coree`): independently publishable Windows Forms apps. Does not replace `winforms-coree` or `winformsdi-coree`.
 - Multi-wpf repository template (`multiwpfrepo-coree`): independently publishable WPF apps. Does not replace `wpfapp-coree`.
 - Multi-PowerShell module repository template (`multipowershellrepo-coree`): host TFM selector, staged module tree, `dotnet pack` Gallery nupkg (not `lib/`), real-host tests, DebugHost F5. Does not replace `powershelllib-coree`.

0.4.3 (2026-09-15)

 - Multi-msbuild repository template (`multimsbuildrepo-coree`): netstandard2.0 task packages under `tasks/`, DebugHost F5 consumer, tests, optional benchmark. Does not replace `msbuildtasklib-coree`.

0.4.2 (2026-09-14)

 - Multi-library, multi-analyzer, and multi-console repository templates (`src/prj` + `src/sln`, `--PlaceSolution BesideCsproj`)

 - Optional Nerdbank.GitVersioning (Project default, Repo, or Off / VersionPrefix)
 - Optional Public API analyzers, NuGet vulnerability gate, and `src/global.json` pin
 - Analyzer DebugHost, typography rules, additional-file include/exclude globs
 - Console apps as packable exes with `--PackAsNuGetTool` and publish profiles
 - This pack versions with Nerdbank like the multi templates (`Properties/version.json`)
